Method note

Each listing is manually reviewed using the saved Sept. 9, 2026 listing description and available listing photographs. The reviewer codes whether the material establishes a private bedroom, a shared bedroom, remains unclear, or should be excluded. “Unclear” is used when the available material does not establish whether the sleeping room is exclusive to one occupant. The exported audit preserves the listing ID, source URL, classification, evidence note, review date, prior text-only audit result and saved photo count.
