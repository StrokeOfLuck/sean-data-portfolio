Celsius to Fahrenheit on the Intel 8085

Assembly programming · Wake Technical Community College · Fall 2020

I wanted to revisit this project because it captures my introduction to programming: working directly with registers, memory addresses, flags and jumps before generative-AI coding assistants became part of everyday programming.

While earning my associate degree in Electronics Engineering Technology at Wake Technical Community College, I wrote an Intel 8085 assembly program that converts Celsius inputs into two-digit BCD Fahrenheit.

Assembly Intel 8085 BCD arithmetic Technical foundations

The assignment

Read a Celsius value from memory address 2000h, convert any input from 0–37°C into Fahrenheit, store the two-digit binary-coded decimal result at 2001h, and document the program with a flowchart and comments.

The code below preserves the instruction sequence and logic I submitted in 2020, including the commented testing harness and the explanations I wrote while learning the material.

1. Divide by five

The program repeatedly subtracts five, using register C to count the quotient and the accumulator to retain the remainder.

2. Multiply by nine

It repeatedly adds the quotient and uses DAA to keep the intermediate value in binary-coded decimal.

3. Store the result

After adding the rounded remainder contribution and 32, it writes the BCD Fahrenheit value to memory address 2001h.

The interactive chart is a browser-native recreation of the flowchart submitted with the program in October 2020. Its shapes, branches and connections follow the original layout, with clarified wording and highlighting linked to the assembly instructions. View the original PDF.
